# 🐍 Exercícios Básicos em Python

Este repositório reúne uma coleção de exercícios desenvolvidos em Python como parte dos meus estudos em lógica de programação e dos primeiros passos na linguagem.

🎯 O principal objetivo deste projeto é fortalecer a base da programação por meio de desafios práticos, aplicando conceitos essenciais como variáveis, operadores aritméticos, entrada e saída de dados, estruturas condicionais (if, elif e else), cálculos matemáticos, conversões de unidades e manipulação de informações fornecidas pelo usuário.

Cada exercício foi desenvolvido para simular pequenas situações do cotidiano, permitindo praticar a construção de algoritmos, o raciocínio lógico e a resolução de problemas de forma gradual. Ao longo dos desafios, foi possível compreender como transformar uma necessidade em uma sequência lógica de instruções utilizando Python.

🚀 Exercícios desenvolvidos

🧮 Dobro, Triplo e Quádruplo
Programa que recebe um número inteiro e calcula seu dobro, triplo e quádruplo.

📚 Média de Notas
Cálculo da média aritmética entre duas notas informadas pelo usuário.

📏 Conversão de Medidas
Conversão de metros para centímetros, milímetros e quilômetros.

📐 Área do Retângulo
Cálculo da área de um retângulo utilizando largura e altura.

🚗 Consumo de Combustível
Cálculo do consumo médio (Km/L) e do valor gasto com combustível a partir da distância percorrida e dos litros abastecidos.

👨‍💼 Cadastro de Funcionário
Cadastro das informações de um funcionário, exibindo nome, horas trabalhadas e valor recebido por hora.

🛒 Compra com Desconto
Simulação de uma compra com cálculo do valor total, aplicação de desconto e exibição do valor final.

🌡️ Conversão de Temperatura
Conversão de temperatura de graus Celsius para Fahrenheit.

🎂 Cálculo de Idade
Determinação da idade atual do usuário e verificação do ano em que ele completa 50 anos.

🎓 Situação do Aluno
Análise da nota final de um aluno, considerando uma atividade extra, e definição da situação acadêmica (Aprovado, Recuperação ou Reprovado).

🛠️ Tecnologias utilizadas
🐍 Python
🎓 Objetivo 

Este repositório representa minha evolução prática em programação e faz parte da construção da minha base em Python. A proposta é documentar minha jornada de aprendizado por meio de exercícios progressivos, reforçando conceitos fundamentais que serão aplicados em projetos mais avançados no futuro.

Além de servir como registro da minha evolução, este repositório demonstra meu compromisso com a prática constante, o desenvolvimento do raciocínio lógico e a construção de uma base sólida para atuar na área de tecnologia. 🚀
